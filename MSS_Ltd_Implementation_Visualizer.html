ASA 5505 Security Architecture & Inspection Policy

The ASA 5505 operates with security levels: Inside (Security Level 100) and Outside (Security Level 0). Higher security level traffic is permitted outbound automatically, and return state table entries are dynamically created.

policy-map global_policy
 class inspection_default
  inspect icmp
  inspect http
  inspect dns
! Route all internal subnets back to HSRP virtual IP on transit:
route inside 192.168.0.0 255.255.0.0 10.255.0.4 1
