# MSS Ltd Network Design Coursework

Coursework resources for designing, implementing, and evaluating a secure and resilient MSS Ltd network in Cisco Packet Tracer.

The network separates Marketing, Sales, and General Support into VLANs and includes DHCP, internal services, database and backup servers, Internet access, firewalling, access controls, and core/link redundancy.

## Start here

1. Read the coursework brief in [`CST4562_CW.pdf`](CST4562_CW.pdf).
2. Follow [`MSS_Ltd_Complete_Beginner_Implementation_Guide.md`](MSS_Ltd_Complete_Beginner_Implementation_Guide.md) for a guided build, or [`implementation-steps.md`](implementation-steps.md) for the concise implementation sequence.
3. Open [`MSS_Ltd_Final.pkt`](MSS_Ltd_Final.pkt) in Cisco Packet Tracer to inspect or test the completed network.
4. Use [`vuln_implementation.md`](vuln_implementation.md) to plan and document the vulnerability analysis.

## Requirements

- Cisco Packet Tracer to open the `.pkt` file
- A modern web browser for the HTML visualizer and SVG diagram
- A Mermaid-compatible viewer or editor if modifying the `.mmd` source

## Important note

This project is an educational simulation. Only perform security testing against systems you own or have explicit permission to test; do not scan university, public, personal, or production networks.
